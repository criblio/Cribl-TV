# Welcome to the Cribl-TV Repo!
This is the place to go if you're looking for tutorials, sample files, and other ephemera mentioned in any of the Cribl video series. 

Currently, you'll find files for:

## Cribl On Your Coffee Break
All the files are found [here](https://github.com/criblio/Cribl-TV/cribl-on-your-coffee-break), and are useful if you're watching the [YouTube series](https://www.youtube.com/watch?v=SOEss_BMkXE&list=PLQemen2vk_As) of the same name. 

## MTTJ (Mean Time to Joy)
This folder contains all the files, explanations, and pre-sets needed to do your very own speedrun based on episodes from the [MTTJ Video Series](). Each episode is contained in a different sub-sub folder.
