# MTTJ (Mean Time to Joy)

This folder contains all the files, explanations, and pre-sets needed to do your very own speedrun based on episodes from the [MTTJ Video Series](). Each episode gets its own folder below.

## Episode 1: OTel On the Go

Get OpenTelemetry trace data into and back out of Cribl Stream in a five-minute speedrun - creating an OTel Source, picking an OTLP version, choosing gRPC vs HTTP, and sending it back out through an OTel Destination.

Files and setup instructions are in [episode-1-otel-on-the-go](./episode-1-otel-on-the-go/README.md).
